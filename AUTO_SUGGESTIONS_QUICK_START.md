# Auto-Gradient Suggestions - Quick Start Guide

## What Is This?

SteelBuild Pro now automatically suggests the perfect gradient theme for your projects based on what you're building. The system looks at your project type, name, client, location, and other details to recommend the best aesthetic match.

## Where You'll See It

### 1. **Project Dashboard Banner** (Most Common)
When you open a project, a smart suggestion banner appears at the top:

```
┌─────────────────────────────────────────────────────────────┐
│ ✨ Smart Aesthetic Suggestion                               │
│ We've detected a perfect gradient match for this project    │
│                                                              │
│ [Preview] Steel Forge                                       │
│          Matches Structural Steel project type    95% match │
│                                                              │
│          [+2 more]  [Apply Now]                    [×]      │
└─────────────────────────────────────────────────────────────┘
```

**What to do:**
- Click **"Apply Now"** to use the suggested gradient
- Click **"+X more"** to see other options
- Click **[×]** to dismiss (won't show again for this project)

### 2. **New Project Form** (During Creation)
As you fill out project details, suggestions appear automatically:

```
Project Type: [Structural Steel ▼]

✨ Suggested Themes

┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│  [Preview]   │  │  [Preview]   │  │  [Preview]   │
│ Steel Forge  │  │ Industrial   │  │ Commercial   │
│ Best match ★ │  │ Power        │  │ Rise         │
│ Matches your │  │ Bold energy  │  │ Professional │
│ project type │  │ aesthetic    │  │ look         │
└──────────────┘  └──────────────┘  └──────────────┘
```

**What to do:**
- Keep typing - suggestions update automatically
- Click any suggestion to select it
- Your selection applies when you create the project

## How It Works

The system analyzes:

1. **Project Type** - Structural Steel, Commercial, High-Rise, etc.
2. **Project Name** - Keywords like "tower", "hospital", "bridge"
3. **Client Name** - Industry indicators
4. **Location** - Geographic region
5. **Budget** - High-value projects get premium aesthetics
6. **Current Season** - Time-appropriate themes

### Examples

| Your Project | Suggested Gradient | Why |
|--------------|-------------------|-----|
| "Memorial Hospital Expansion" | Healthcare Calm | Detected "hospital" keyword |
| "Downtown Tower - $50M" | High-Rise Elite | High budget + tower keyword |
| Phoenix Steel Plant | Desert Dusk | Location + industrial type |
| Bridge Project - Winter Start | Infrastructure Core + Winter Steel | Bridge type + season |

## Match Confidence

Each suggestion shows a confidence percentage:

- **95% match** (High) - Strong contextual fit, highly recommended
- **75% match** (Medium) - Good fit, worth considering
- **50% match** (Low) - Possible match, explore alternatives

## How to Use

### Quick Apply (Recommended)
1. See suggestion banner on project dashboard
2. Click **"Apply Now"**
3. Done! Gradient is applied immediately

### Review Multiple Options
1. See suggestion banner
2. Click **"+X more"** button
3. Review all suggestions with reasons
4. Click **"Apply"** next to your preferred choice

### Choose During Project Creation
1. Start creating a new project
2. Fill in Project Type and Name
3. Review suggested themes below form
4. Click on your preferred suggestion
5. Complete form and create project
6. Gradient auto-applies to new project

### Manually Browse (Anytime)
1. Go to Project Settings
2. Click "Appearance" tab
3. Click "Change Gradient" button
4. View "Smart Suggestions" tab
5. Browse and select

## Managing Suggestions

### Don't Want Suggestions?
Click the **[×]** button on the banner. It will never show again for that project. You can still manually change gradients in settings.

### Already Have a Custom Gradient?
Suggestions won't appear. The system respects your manual choices.

### Want Suggestions Back?
Clear your dismissed state in Settings > Appearance > Reset Suggestions.

## Tips for Better Suggestions

### ✅ Do This
- Use descriptive project names: "Memorial Hospital Tower Addition"
- Select accurate project types
- Include location when relevant
- Add client name if they have industry-specific terms

### ❌ Avoid This
- Generic names: "Project 2024-03"
- Missing project type selection
- Abbreviations only: "ASM-PHX-24"

## Troubleshooting

**Not seeing suggestions?**
- You may have dismissed them previously
- Project may already have a custom gradient
- Try adding more project details (type, name, client)

**Wrong suggestions showing?**
- Check your project type is correct
- Review project name for misleading keywords
- Location field affects regional themes

**Want to change after applying?**
- Go to Project Settings > Appearance
- Choose any gradient manually
- Your choice will override the suggestion

## FAQ

**Q: Will this change my existing projects?**  
A: No. It only suggests for new projects or projects without custom gradients.

**Q: Can I ignore suggestions?**  
A: Yes. Click the × to dismiss. Or just don't click "Apply Now".

**Q: Can I see suggestions for old projects?**  
A: Yes. Go to that project's Settings > Appearance and view suggestions there.

**Q: Do suggestions sync across devices?**  
A: Your dismissed state syncs via your account. Suggestions calculate fresh on each device.

**Q: Can I create my own rules?**  
A: Not yet in the UI, but developers can extend the suggestion logic.

**Q: Does this slow down the app?**  
A: No. All calculations are instant and run locally in your browser.

**Q: Can I suggest improvements?**  
A: Yes! Submit feedback in Settings > About > Provide Feedback.
